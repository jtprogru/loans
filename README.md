# loans

Личный журнал рублёвых займов между физлицами: показывает, сколько осталось вернуть на сегодня или на выбранную дату. Деньги приложение не переводит, к банкам и сети не подключается.

## Сборка и запуск

Нужен Go 1.27 или новее. SQLite встроена в бинарник; CGO и отдельный сервер не нужны.

```sh
make build.bin
./dist/loans                   # полноэкранный TUI
./dist/loans --help            # команды и форматы аргументов
make test                      # тесты и порог покрытия 90% по всему модулю
```

Можно запустить без сборки отдельного файла: `go run ./cmd/loans`.

### TUI

Интерфейс на Bubble Tea v2 занимает всё окно терминала. Верхняя полоса показывает текущий раздел, нижняя — доступные клавиши. Активная строка и поле ввода отмечены цветом и знаком `›`.

- **↑/↓**, **PgUp/PgDn** — прокрутка, **Enter** — открыть карточку, **/** — поиск по имени или ID.
- В списке: **n** — новый должник, **k** — ключевая ставка, **e** — экспорт, **i** — восстановление, **q** — выход.
- В карточке: **e** — изменить имя, сумму, дату или условия займа; **P** (Shift+p) — исправить сумму или дату существующего платежа по ID. Обе формы заполнены текущими значениями. Сохранение пересчитывает историю; недопустимая правка откатывается целиком.
- В карточке: **p** — записать платёж, **x** — удалить платёж, **D** — удалить карточку с её платежами; **d** — выбрать дату отчёта, **t** — вернуться к сегодняшней дате, **Esc** — назад.
- В справочнике: **s** — сохранить ставку, **c** — подтвердить проверенный интервал.
- Поле периода появляется только для числовой ставки. Пустой период означает год. Без ставки или с `key-rate` период не запрашивается.
- В формах **Tab/Shift+Tab** переключает поля, **Enter** применяет изменения, **Esc** отменяет. Для удаления и восстановления нужно отдельно подтвердить действие клавишей **y**.

### CLI

```sh
loans debtor add --name 'Анна' --amount 10000 --date 2025-01-31
loans debtor list
loans balance 1
loans balance 1 --date 2025-03-31
loans payment add 1 --amount 4000 --date 2025-03-10
loans payment list 1
loans payment delete 1 --payment-id 1 --yes
loans debtor delete 1 --yes
```

Даты пишутся как `YYYY-MM-DD`, суммы — в рублях с точностью до двух знаков (разделитель — точка или запятая). `balance` без даты использует местную календарную дату.

Без `--rate` договор считается не содержащим условия о процентах: до 100 000 ₽ включительно применяется 0%, выше — ключевая ставка. `--rate 0` явно задаёт беспроцентный договор; `--rate key-rate` — договор с процентами без указанного размера. Для `--rate 10` ставка равна 10% годовых, для `--rate 10 --period 21d` — 10% за 21 день; `--period 1m` означает календарный месяц с границами от даты выдачи. По умолчанию платёж идёт сначала в проценты, затем в тело. Меняйте порядок через `--repayment principal-first`, только если это предусмотрено договором.

### Ключевая ставка

Значения и даты вступления в силу сверяются вручную с [историей Банка России](https://www.cbr.ru/hd_base/KeyRate/). Введите все изменения за нужный период, включая ставку, действующую в его первый день, и только тогда отметьте этот интервал проверенным. Например, ниже **условные данные для тестовой базы**, а не история ЦБ:

```sh
loans --db demo.sqlite3 key-rate set --date 2025-01-02 --rate 10 --source 'Тестовые данные'
loans --db demo.sqlite3 key-rate set --date 2025-01-03 --rate 12 --source 'Тестовые данные'
loans --db demo.sqlite3 key-rate coverage --from 2025-01-02 --through 2025-01-03
loans --db demo.sqlite3 key-rate list
```

Если нужные дни не покрыты, приложение показывает недостающий интервал вместо неподтверждённой суммы. Проценты начисляются только пока остаток тела положительный.

## База, журнал и копии

По умолчанию база создаётся в `~/.config/loans/loans.sqlite3`, где `~` — домашний каталог пользователя. Путь можно изменить глобальным флагом `--db PATH`. Старая база автоматически не переносится: чтобы продолжить работу с ней, укажите прежний путь через `--db`. CLI и TUI используют одну базу. Рядом с ней находится локальный журнал `<имя базы>.log`: он фиксирует действия и их исход, но не содержит карточек, сумм или содержимого копий. Причины ошибок отображаются в интерфейсе.

```sh
loans backup export loans-backup.json
loans --db restored.sqlite3 backup import loans-backup.json
loans backup import loans-backup.json --replace
```

JSON — полная копия с исходными ID и условиями, а не рабочая база. Восстановление **заменяет**, а не объединяет данные; непустую базу нельзя заменить без `--replace` или подтверждения в TUI. Копия содержит персональные данные и суммы — храните её в закрытом месте. Старый прототип с `STORAGE_TYPE=JSON` не используется; его формат не является резервной копией.

## Структура проекта

- `cmd/loans` — точка входа.
- `internal/ledger` — условия, календарные правила и воспроизведение истории.
- `internal/store` — SQLite, транзакции и резервные копии.
- `internal/cli`, `internal/tui` — интерфейсы; `internal/display` — общий формат вывода; `internal/audit` — журнал.

Расчёт ведётся по внесённым условиям и платежам и не подтверждает, что сумму можно взыскать. Банковские кредиты, займы МФО, капитализация и издержки получения исполнения не учитываются.
